# Direction artistique — menu, panorama et effets

Création avec le générateur d’images intégré. Les illustrations sont intégrées dans Unity ; les décors sont découpés sans perte dans Unity en trois PNG contigus. Les personnages précédents sont conservés.

## Fichiers livrés

- `Assets/ArtSources/menu-logo.png` : titre illustré transparent (remplacé par `Art/action-legends-logo.png`, sorti de `Resources` en 0.8.0).
- `Assets/Resources/Art/menu-card.png` : cadre métallique utilisé par les fiches de héros et la mission.
- `Assets/ArtSources/route-master.png` : fresque continue originale.
- `Assets/Resources/Art/route-01.png`, `route-02.png` et `Assets/ArtSources/route-03.png` (plus affiché depuis 0.8.0) : boulevard, quais de Seine et Bastille.
- `Assets/Resources/Art/arcade-fx.png` : 24 images d’animation, flammes de bouche, impacts, explosions et poussière.

Les dimensions reçues diffèrent parfois des dimensions souhaitées. Le moteur calcule le découpage à partir des dimensions réelles. La transparence des effets est contrôlée dans Unity et leurs bords s’estompent légèrement à l’affichage pour éviter les rectangles visibles.

### Correction de transparence des effets

Edit target: this 6-column by 4-row VFX atlas. Keep the exact 24 effects, exact cell layout, positions, chronological frame sequence, core colors, fine pixel-art detail and all distinct flames, sparks, debris and smoke. Change ONLY transparency/background: REMOVE the entire dark blue/orange atmospheric backdrop and ALL broad colored haze extending into cell gutters. Make every cell's empty space FULLY TRANSPARENT ALPHA (alpha 0), especially every outer edge and the entire gutters between effects. Do not replace the backdrop with black, white, checkerboard or any solid color. Each effect must be an isolated, tightly bounded transparent game sprite with a completely clear transparent margin on all four sides. Retain the painted blue-gray smoke cloud shapes but remove diffuse global lighting behind them. No broad glows, no gradient backgrounds, no new text, no grid lines. Return production PNG with real transparency; this will be sliced into 24 cells in Unity, so any opaque background rectangle would be unusable.

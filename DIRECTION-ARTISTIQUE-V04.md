# Action Legends — identité du jeu

Le nom du jeu est désormais Action Legends. Panique à Paname reste la première mission et le titre de ses anciens visuels. Un nouveau logo global a été créé avec le générateur d’images intégré, en conservant le style de lettres arcade sans les monuments de Paris.

Fichiers : `Assets/Resources/Art/action-legends-logo.png` pour le menu Unity ; `Assets/WebGLTemplates/ActionLegends/logo.png` pour la page navigateur.

## Prompt final

Create a new global game-title logo, matching the reference image's beautiful original arcade lettering and polished rendering. Exact text: ACTION LEGENDS, two words on two compact lines, highly readable. Keep the chunky leaning cream-to-orange enamel faces, thick deep-navy extruded shadows, small weathered chips and restrained sparks. Remove every Paris-specific landmark, Eiffel Tower and skyline; this is the title of a global action game with levels in many places. Real transparent background outside the lettering. No extra words, no existing franchise logo, no rectangular backdrop. Wide horizontal composition, roughly 3:1. Production UI art for a Unity game menu.
